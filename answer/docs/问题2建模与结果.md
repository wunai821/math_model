# 问题2：怎么把冲突“挪开”

## 1. 题目要我们回答什么

问题1找出了297对冲突。本问要为每台装备重新安排一个合法状态，使剩下执行的计划之间不再冲突，同时尽量少撤销、少调整。

可以把每台装备的处理方式理解成三选一：

- 频率整体平移一点；
- 第一次使用时间整体平移一点；
- 直接撤销这台装备。

调整后，频宽、单次时长、使用间隔和使用次数都不能改变。

## 2. 允许怎么调整

对装备 `i` 设置：

- 频移 `u_i`：整数，`-10≤u_i≤10`；
- 首次时间平移 `v_i`：整数，`-5≤v_i≤5`；
- 撤销标记 `z_i`：0表示保留，1表示撤销。

同一台装备最多只做一种调整，所以不能同时频移和时间平移；撤销时两种平移都必须为0。调整后还要满足：

```text
0 ≤ a_i+u_i < b_i+u_i ≤ 100
s_i+v_i ≥ 0
```

第 `k` 次使用的时间区间变为：

```text
[s_i+v_i+k(d_i+g_i), s_i+v_i+k(d_i+g_i)+d_i)
```

本问只使用题目明确给出的“平移幅度”和“首次时间非负”限制，不额外假设一个统一的最后结束时间。

## 3. 冲突约束怎么写

对任意两台没有撤销的装备，至少要满足下面一个条件：

1. 调整后的频段完全分开；或
2. 两台装备的所有重复使用时间区间完全分开。

频段分开可以写成：

```text
b_i+u_i ≤ a_j+u_j
或
b_j+u_j ≤ a_i+u_i
```

时间端点相接是合法的，因为统一使用左闭右开区间。程序会把每台装备的全部重复时段都展开，再检查调整后可能新出现的冲突，而不是只检查问题1中已经发现的冲突。

为减少模型规模，程序预先计算每对装备的相对时间平移 `v_i-v_j` 哪些取值是安全的，再把“所有重复时间不冲突”压缩成一个允许取值集合。另有一个枚举候选的网格模型作为交叉参考；两种模型采用同样的题目约束。

## 4. 多目标怎么处理

题目没有给出数值权重，因此采用容易解释的“先后顺序”优化，也叫字典序优化：

1. 先让撤销总数尽可能少；
2. 在此基础上，让A类撤销尽可能少；
3. 再让B类撤销尽可能少；
4. 再让调整总数尽可能少；
5. 再分别减少A类、B类调整数；
6. 最后减少平移幅度。

最后一项使用 `Σ(|u_i|+2|v_i|)`。时间平移的最大允许幅度是5，频移的最大允许幅度是10，所以乘2后两类幅度处于可比较尺度；它等于归一化幅度和的10倍。

每完成一层，就把这一层的结果锁住，再进入下一层。限时阶段如果只找到可行方案，就保留“当前值、下界和状态”，不把 `FEASIBLE` 说成全局最优。

## 7. 专业解题流程（可直接写进论文）

1. **数据整理**：读取150项原始计划，计算每台装备的重复使用区间。
2. **变量设计**：为每台装备设置频移、时间平移和撤销变量。
3. **合法性约束**：限制平移幅度、频段边界、首次时间非负，并保证“一台装备最多一种操作”。
4. **冲突约束**：对所有装备对检查调整后的频段和全部重复时间区间。
5. **分层优化**：按撤销数、类别撤销数、调整数、调整幅度依次求解。
6. **独立复核**：不用求解器内部判断，重新展开所有区间，检查零冲突和模板填写是否正确。

## 9. 一句话结论

问题2用“尽量少撤销、再尽量少调整”的顺序，把297对冲突全部消掉：撤销6项、调整126项、保留18项，最终144项计划可以同时执行。

## 模型作用与完整步骤（详细版）

### 这个模型到底解决什么问题

问题1只告诉我们“哪里冲突”，问题2要进一步回答“每台装备应该怎么改”。这不是简单地把某一台装备往后挪，因为一台装备的调整可能会：

- 消除它与甲的冲突，却制造它与乙的新冲突；
- 影响全部重复使用时段，而不只是第一次使用；
- 受到频率边界、时间不能为负和“只能改一个参数”等限制。

所以问题2模型的作用是：**从每台装备的合法操作中各选一个状态，并保证所有被保留的装备两两不冲突。**在所有可行方案中，再按照题目要求的优先级挑出最合适的一套。

### 变量分别代表什么

| 变量 | 取值 | 在现实中的意思 |
|---|---|---|
| `u_i` | -10到10的整数 | 装备i的整段频率向左/向右挪多少格 |
| `v_i` | -5到5的整数 | 装备i的所有重复时段整体向前/向后挪多少格 |
| `z_i` | 0或1 | 是否撤销装备i |
| `changed_i` | 0或1 | 是否发生了频移或时间平移 |

这些变量不是“随便给一个数字”。模型还会检查它们组合起来是否满足题目规则；例如`u_i=2,v_i=1`虽然两个数都在范围内，但因为同时改了两个参数，整个组合仍然是非法的。

### 四类约束各自起什么作用

1. **频率边界约束**：保证平移后仍在`[0,100)`内，不能挪出可用频率资源。
2. **时间合法约束**：保证首次时间不小于0；重复时段按照同样的时长和间隔向后展开。
3. **单参数操作约束**：一台装备只能原样保留、只频移、只时间平移或撤销，不能把多个动作叠加。
4. **装备对避让约束**：对每一对可能冲突的装备，至少发生一件事——撤销一台、频段分开，或者全部重复时间错开。

这些约束共同保证“模型找到的方案可以实际执行”。其中第4类必须对调整后的新位置重新判断，不能只针对问题1已经发现的297对冲突加约束。

### 为什么使用紧凑模型

如果把每台装备的每一个整数频率格和每一个时间格都展开，变量和资源约束会非常多。紧凑模型抓住了一个事实：对一对装备而言，时间是否安全只取决于相对平移`v_i-v_j`。因此先把安全的相对差值算好，再将其作为一个离散允许集合加入模型。

这样做的好处是：

- 模型规模更小，CP-SAT更容易搜索；
- 仍然检查全部重复时段，不是用近似代替精确判断；
- 还可以用参考网格模型交叉验证。

### 七层优化为什么要分开做

如果直接把“撤销数”和“调整幅度”相加，就必须人为决定权重，容易出现“少改一点幅度但多撤销一台”的不符合题意结果。本项目按字典序分七层：

1. 先最大限度保留装备（最小化撤销总数）；
2. 在保留数量相同的方案中优先保留A类；
3. 再优先保留B类；
4. 再减少需要调整的装备数；
5. 再分别减少A类、B类调整数；
6. 最后才比较平移幅度。

每层的结果都被锁定后才进入下一层，因此后面的“成本更小”不能牺牲前面已经达到的保留数量。

### 从输入到结果的完整执行步骤

1. **读取原始计划**，并计算每台装备的频段和重复时段。
2. **为每台装备建立合法取值域**：频移域、时间平移域和撤销状态。
3. **加入单参数限制**，排除同时频移和时间平移的组合。
4. **逐对建立避让约束**，覆盖调整后可能产生的新冲突。
5. **依次求解七个目标**，每层结束后写入阶段值、下界和状态。
6. **保存完整方案**：不仅保存Excel中要填的行，也保存所有未调整但仍执行的装备，供问题3读取。
7. **独立验证**：重新读取附件和方案，检查权限、边界、不变量、全部重复区间和最终冲突。
8. **导出Excel**：把频移、时间平移和撤销分别写到模板规定的列中。

### 如何理解“可行”和“最优”

- **可行**：当前这套方案没有违反约束，且验证器确认零冲突；
- **阶段最优**：在前面目标已经锁定的前提下，这一层已经证明无法更好；
- **全局字典序最优**：七层目标全部都证明最优。

本问只有撤销总数6和A类撤销0已证明最优，后续目标是经过验证的可行结果，不应把整套方案说成七层全局最优。

## 10. 源码解读：模型如何把“挪开”写成约束

问题2主要由 `src/q2/solve_compact.py` 和 `src/q2/solve.py` 完成。前者负责紧凑的CP-SAT模型，后者提供原始计划读取和参考网格模型；`src/q2/verify.py` 完全独立地检查最终方案。

### 10.1 `safe_differences`：先算出哪些相对时间差安全

源码先把两台装备所有可能的相对时间平移 `d=-10,...,10` 逐一试一遍：

```python
for d in range(-10, 11):
    overlap = any(
        sa + d < eb and sb < ea + d
        for sa, ea in intervals(a)
        for sb, eb in intervals(b)
    )
    if not overlap:
        result.append(d)
```

如果某个 `d` 让全部重复时段都不重叠，就把它放进安全集合。这样求解时不用反复展开所有时间区间，只需要判断 `v_i-v_j` 是否属于这个集合。

### 10.2 `add_allowed_assignments`：限制一台装备只能做一种操作

源码用允许组合表表达“原样、只频移、只时间平移”三种情况：

```python
model.add_allowed_assignments(
    [f, t, changed],
    [(0, 0, 0)]
    + [(x, 0, 1) for x in fv if x]
    + [(0, x, 1) for x in tv if x]
)
```

表中没有 `(非零频移, 非零时间平移, 1)`，所以模型天然禁止两种平移同时发生。撤销变量为真时，代码还强制 `f=t=changed=0`。

### 10.3 `model.add_bool_or`：给每一对装备至少留一条避让路

对一对可能冲突的装备，源码把“撤销、频段在前、频段在后、时间安全”放进同一个或约束：

```python
terms = [cancel_i, cancel_j, i_before_j, j_before_i]
if safe:
    terms.append(time_safe)
model.add_bool_or(terms)
```

这句话的意思是：两台装备不能同时占用同一块资源，但不要求所有装备都必须改频率。只要撤销一台、频段分开，或者重复时间完全错开，冲突就被消除了。

### 10.4 七层目标如何落到代码

源码把目标按顺序放入 `objectives` 列表：

```python
cancel_total → cancel_A → cancel_B →
adjust_total → adjust_A → adjust_B → shift_cost
```

每完成一层，就执行 `model.add(expr == value)` 锁定当前结果，再求下一层。每个阶段都把状态、当前值和下界写入 `solution.json`，因此文档可以区分 `OPTIMAL` 和 `FEASIBLE`，不会把限时可行解误写成全局最优。

最后，`save(...)` 将每台装备的 `df`、`dt`、`canceled` 转成完整方案和附件2需要的行；`verify.py` 再重新计算区间和冲突，不依赖模型内部的候选占用表。

## 进一步拆解：求解器的一轮搜索到底做了什么

### 第一步：为每台装备生成“可选动作菜单”

以一台频段为`[35,40)`、首次时间为`[100,105)`的装备为例，源码会根据边界生成：

- 频移`u`的合法集合：可能是`-10,...,10`，但如果原频段靠近0或100，会自动删掉越界值；
- 时间平移`v`的合法集合：`-5,...,5`，但如果首次时间小于5，会删掉导致负时间的值；
- 撤销状态：不占资源，但保留装备编号以便统计。

因此，模型不是在连续时间里“随便挪一点”，而是在题目规定的整数格点上选择一个确定方案，结果可以直接填回Excel。

### 第二步：把“只能改一个参数”变成允许表

模型中的`f`、`t`不是最终频段和时间，而是相对原计划的偏移量。允许表只包含三类组合：

| `f` | `t` | `changed` | 含义 |
|---:|---:|---:|---|
| 0 | 0 | 0 | 原样保留 |
| 非0 | 0 | 1 | 只频移 |
| 0 | 非0 | 1 | 只平移首次时间 |

撤销变量为1时，代码把`f`、`t`和`changed`都强制为0。这样“撤销”和“调整”在统计上不会混在一起，题目表中的三列也能互相对应。

### 第三步：对一对装备判断“至少满足一个避让条件”

源码不会强迫所有冲突装备都去频移。对于装备i和j，它只要求以下条件中至少一个成立：

```text
cancel_i = 1
或 cancel_j = 1
或 i的频段在j左边
或 j的频段在i左边
或 v_i-v_j属于安全差值集合
```

这是一条“或”约束，表示模型可以自己选择最省代价的避让方式。比如频段已经能错开，就不必再平移时间；如果两台装备频段很难错开，也可以用相对时间平移解决。

对于根本不可能发生频率重叠的装备对，源码直接跳过；对于任意相对时间差都安全的装备对，也跳过时间约束。这两种剪枝只是在减少模型规模，不会改变可行方案集合。

### 第四步：一层一层求解，而不是一次猜权重

代码的阶段循环可以写成下面的伪代码：

```text
for 当前目标 in 七个目标:
    求解当前目标的最小值
    如果得到可行解：保存当前方案、当前值、下界和状态
    把当前值加成等式约束
    进入下一目标
```

例如第一阶段得到“撤销6项”，第二阶段就会加入`撤销总数=6`，因此第二阶段不可能通过撤销7项来换取更少的调整。这个“锁定”动作是字典序优化的关键。

### 第五步：缓存、提示方案和最终导出

每个阶段完成后，`save(...)`都会写入`solution.json`。文件中同时有：

- 150台装备的完整最终状态；
- Excel需要填写的调整/撤销行；
- A/B/C分类统计；
- 七个目标的阶段记录。

下次运行时，`load_hint(...)`可以把旧方案作为提示，加快搜索，但提示只用于加速，不会绕过独立验证。`verify.py`会重新从附件计算区间，再确认操作权限、频段边界、时间非负、参数不变量和零冲突；只有通过后，`export_xlsx.py 2`才应该生成提交表。

### 如何读一条最终方案记录

例如某台装备记录`df=3, dt=0, canceled=false`，表示频段整体右移3格，首次时间不变；如果`df=0, dt=-2`，表示首次使用和所有重复时段整体提前2格；如果`canceled=true`，则它不参与冲突计算，Excel的撤销列填“是”。
