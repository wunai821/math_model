# 问题1：先找出哪些装备“撞车”

## 1. 题目要我们回答什么

附件1给出了150项用频计划。每项计划规定了一段频率、第一次使用时间、每次使用多久、两次使用之间隔多久，以及一共重复使用多少次。

本问只做一件事：找出所有存在时频冲突的装备对，并按附件2的格式输出。这里的“冲突”不是只看频率相交，也不是只看时间相交，而是要求**频率相交，并且至少有一对实际使用时段也相交**。

## 2. 先把一项计划翻译成区间

所有区间都用左闭右开表示。例如 `[0,10)` 包含0但不包含10，因此 `[0,10)` 和 `[10,20)` 只是端点相接，不算冲突。

对装备 `i`，记：

- 频段为 `[a_i,b_i)`；
- 第一次使用时间为 `[s_i,e_i)`；
- 单次使用时长 `d_i=e_i-s_i`；
- 两次使用之间的空闲间隔为 `g_i`；
- 使用次数为 `n_i`。

因为每次使用都按“时长+间隔”向后重复，第 `k` 次开始时间为：

```text
τ(i,k) = s_i + k(d_i + g_i),  k = 0,1,...,n_i-1
```

第 `k` 次使用区间就是 `[τ(i,k), τ(i,k)+d_i)`。例如 A001 的三个时段是 `[35,40)`、`[100,105)`、`[165,170)`。

## 3. 怎么判断两台装备冲突

对任意两台不同装备 `i` 和 `j`，按下面顺序判断：

1. 看频段是否重叠：

   ```text
   max(a_i,a_j) < min(b_i,b_j)
   ```

2. 如果频段重叠，再枚举两台装备的所有重复时段，检查是否存在一对时间区间重叠：

   ```text
   max(τ(i,k),τ(j,l)) < min(τ(i,k)+d_i,τ(j,l)+d_j)
   ```

3. 两个条件同时成立，就记录一次装备对 `{i,j}`。

也可以把装备画成点、把冲突画成边，得到“冲突网络”。同一对装备即使有多次时段重叠，也只记一条边；题目要的是不同装备对的数量。

## 4. 求解和复核流程

本问不需要复杂优化，直接做完整枚举：

1. 先检查全部 `C(150,2)=11175` 个无序装备对；
2. 频段不重叠的对直接跳过；
3. 频段重叠的对再逐个检查重复时间区间；
4. 将冲突对去重后写入 `data.json` 和 `result1.xlsx`；
5. 再用独立的离散时频网格方法复核，确保两种方法得到同一批冲突对。

区间法的最坏复杂度约为 `O(N²K²)`，`N` 是装备数，`K` 是单台装备最大重复次数。由于所有数据规模都不大，完整枚举可以直接完成，避免了抽样或只找“看起来严重”的冲突。

## 模型作用与完整步骤（详细版）

### 这个模型到底解决什么问题

题目中的“冲突”如果只用自然语言描述，容易出现三种误判：

- 频率重叠，但两台装备从来不是同一时刻使用，这不应算冲突；
- 时间重叠，但频率完全分开，这也不应算冲突；
- 第一次使用不重叠，但第二次或更后面的重复使用发生重叠，这不能漏掉。

因此，问题1模型的作用是把“冲突”变成一个可以逐项检查的布尔条件：

```text
频率区间相交  AND  至少一对重复时间区间相交
```

模型的输出不是一个估计数量，而是一张完整的装备对清单。后续问题2要消解这张清单中的冲突，图3也正是把这张清单画成网络。

### 输入、计算对象和输出

| 环节 | 内容 |
|---|---|
| 输入 | 附件1中的150项计划 |
| 中间对象 | 每台装备的频段区间、全部重复时间区间 |
| 判断对象 | 150台装备中任意两台组成的11175个无序装备对 |
| 输出 | 去重后的冲突装备对、类别统计、冲突度数、`result1.xlsx` |

### 完整步骤

1. **读取一行计划**：解析装备编号、频率如`[a,b)`、首次时间如`[s,e)`、间隔`g`和次数`n`。
2. **展开重复时段**：先算单次时长`d=e-s`，再按` s+k(d+g)`生成第`k`次开始时间。
3. **检查频率**：如果两个频段不相交，立即跳过，避免无意义的时间枚举。
4. **检查时间**：如果频率相交，则把两台装备的全部重复时段两两比较。
5. **记录装备对**：只要找到一组时间交叠，就记录一次装备对，并停止继续给该对增加边。
6. **汇总统计**：按A–A、A–B等类别计数，同时统计哪些装备被卷入冲突、每台装备有多少邻居。
7. **独立复核**：再把每个整数时频格的占用装备列出来，用网格法重新生成冲突对，与区间法逐项比较。
8. **导出结果**：把去重后的297对按附件2模板写入Excel。

### 一个小例子

假设装备甲占用频段`[10,20)`，装备乙占用频段`[15,25)`，两者频率相交；但甲的时间是`[0,5)`，乙的时间是`[5,10)`，只有端点相接。由于采用左闭右开区间，`[0,5)`与`[5,10)`不重叠，所以这两个计划不算冲突。

如果乙的时间改为`[4,10)`，则时间条件成立，装备甲和乙才会被记为一条冲突边。

### 为什么这个模型可以认为是完整的

完整性来自三个地方：

- `combinations(plans, 2)`覆盖每个无序装备对，既不漏检也不重复检；
- `for`循环覆盖每台装备的全部重复次数，不只看首次时段；
- 两种独立方法得到的集合必须完全相同，源码中用`assert`强制检查。

因此，297不是“抽样得到的冲突数”，而是对这150项计划按统一规则完整枚举后的结果。

## 8. 源码解读：代码如何完成冲突检测

问题1的主程序是 `src/q1/solve.py`，它没有调用复杂优化器，而是把题目中的“频率相交且时间相交”直接翻译成循环判断。

### 8.1 读入数据并展开重复时段

程序从附件1逐行读取装备编号、频段和首次使用时间，再用下面的逻辑得到所有重复时段：

```python
duration = end - start
slots = [
    (start + k * (duration + gap),
     end + k * (duration + gap))
    for k in range(count)
]
```

这段代码对应文中的公式 `τ(i,k)=s_i+k(d_i+g_i)`。后面所有冲突判断都使用 `slots`，所以不会漏掉第二次、第三次等重复使用。

### 8.2 两层循环判断一对装备

核心判断可以简化成：

```python
for a, b in combinations(plans, 2):
    if max(a['lo'], b['lo']) >= min(a['hi'], b['hi']):
        continue                 # 频率不重叠，直接排除
    hits = [
        ... for sa, ea in a['slots']
        for sb, eb in b['slots']
        if max(sa, sb) < min(ea, eb)
    ]
    if hits:
        pairs.append([a['id'], b['id']])
```

第一层先筛掉频率不相交的装备对；第二层才检查所有重复时间区间。`combinations(plans, 2)`保证每对装备只检查一次，`pairs.append`也只记录一条边。

### 8.3 为什么还要再做一次网格复核

源码随后把每个整数时间格和频率格记录到 `occupants` 字典中，再把同一格里的装备两两配对。最后用：

```python
assert grid_pairs == {tuple(sorted(x)) for x in pairs}
```

确认“区间法”和“网格法”得到的冲突集合完全相同。这个 `assert` 是源码中的第二道保险，不是只看程序打印出来的数字。
