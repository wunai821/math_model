# 问题1：时频冲突检测

## 数据与符号

数据来源为附件1.xlsx，共150项用频计划：A类20项、B类40项、C类90项。频率与时间分别以 Δf 和 Δt 为单位。所有区间采用左闭右开形式，端点相接不算交叠。

记装备 i 的频段为 [a_i,b_i)，首次使用时间为 [s_i,e_i)，单次使用时长为 d_i=e_i-s_i，使用间隔为 g_i，使用次数为 n_i。这里 g_i 是前一次结束至下一次开始的间隔，因此第 k 次使用的开始时间为

τ_ik = s_i + k(d_i+g_i)，k=0,…,n_i−1。

第 k 次使用区间为 [τ_ik,τ_ik+d_i)。例如，A001的三个使用区间为 [35,40)、[100,105)、[165,170)。

## 冲突判定模型

对任意不同装备 i、j，首先判断频段是否交叠：

max(a_i,a_j) < min(b_i,b_j)。

若频段交叠，再检查是否存在 k∈{0,…,n_i−1}、l∈{0,…,n_j−1}，使

max(τ_ik,τ_jl) < min(τ_ik+d_i,τ_jl+d_j)。

上述两个条件同时成立，则将装备对 {i,j} 判定为冲突。可构造无向冲突图：装备为顶点，冲突装备对为边。邻接矩阵对称，主对角线为零。

## 求解方法与验证

遍历全部 C(150,2)=11175 个无序装备对，先筛选频段交叠，再枚举两台装备的所有使用时段组合。发现至少一次时间交叠即可将该装备对纳入结果集合。每个装备对仅输出一次，不因重复使用产生多行记录。最坏时间复杂度为 O(N²K²)，其中 K 为单台装备的最大使用次数。

另采用独立的离散时频网格占用法进行复核：逐一记录每个单位时间、单位频段上的占用装备，将同一网格内的装备两两配对并去重。该方法所得冲突对集合与区间判定法完全一致。导出的Excel文件经重新读取，297条记录全部与计算结果一致，序号连续，无重复对。

## 统计结果

| 冲突类别 | 冲突装备对数 |
|---|---:|
| A–A | 0 |
| A–B | 21 |
| A–C | 66 |
| B–B | 10 |
| B–C | 181 |
| C–C | 19 |
| 合计 | 297 |

| 装备类别 | 装备总数 | 涉及冲突的装备数 | 无冲突装备数 |
|---|---:|---:|---:|
| A | 20 | 20 | 0 |
| B | 40 | 40 | 0 |
| C | 90 | 88 | 2 |
| 合计 | 150 | 148 | 2 |

冲突装备对占全部装备对的 297/11175≈2.66%；涉及冲突的装备占 148/150≈98.67%。仅C007、C060未与其他装备发生冲突。B–C类冲突有181对，占全部冲突对的60.94%，是主要冲突类型。

若按两台装备各自的使用时段组合计数，共有431次冲突；此处一次指一组相交的使用区间，不是冲突的单位时间数量。题目要求输出的是297个不同装备对，而非431次时段组合冲突。

单台装备最多与8台其他装备冲突，对应B009、B016、B024、B027、B030、C076。
