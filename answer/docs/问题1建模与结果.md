# 问题1：先找出哪些装备“撞车”

## 1. 题目要我们回答什么

附件1给出了150项用频计划。每项计划规定了一段频率、第一次使用时间、每次使用多久、两次使用之间隔多久，以及一共重复使用多少次。

本问只做一件事：找出所有存在时频冲突的装备对，并按附件2的格式输出。这里的“冲突”不是只看频率相交，也不是只看时间相交，而是要求**频率相交，并且至少有一对实际使用时段也相交**。

## 2. 先把一项计划翻译成区间

所有区间都用左闭右开表示。例如 `[0,10)` 包含0但不包含10，因此 `[0,10)` 和 `[10,20)` 只是端点相接，不算冲突。

对装备 `i`，记：

- 频段为 `[a_i,b_i)`；
- 第一次使用时间为 `[s_i,e_i)`；
- 单次使用时长 `d_i=e_i-s_i`；
- 两次使用之间的空闲间隔为 `g_i`；
- 使用次数为 `n_i`。

因为每次使用都按“时长+间隔”向后重复，第 `k` 次开始时间为：

```text
τ(i,k) = s_i + k(d_i + g_i),  k = 0,1,...,n_i-1
```

第 `k` 次使用区间就是 `[τ(i,k), τ(i,k)+d_i)`。例如 A001 的三个时段是 `[35,40)`、`[100,105)`、`[165,170)`。

## 3. 怎么判断两台装备冲突

对任意两台不同装备 `i` 和 `j`，按下面顺序判断：

1. 看频段是否重叠：

   ```text
   max(a_i,a_j) < min(b_i,b_j)
   ```

2. 如果频段重叠，再枚举两台装备的所有重复时段，检查是否存在一对时间区间重叠：

   ```text
   max(τ(i,k),τ(j,l)) < min(τ(i,k)+d_i,τ(j,l)+d_j)
   ```

3. 两个条件同时成立，就记录一次装备对 `{i,j}`。

也可以把装备画成点、把冲突画成边，得到“冲突网络”。同一对装备即使有多次时段重叠，也只记一条边；题目要的是不同装备对的数量。

## 4. 求解和复核流程

本问不需要复杂优化，直接做完整枚举：

1. 先检查全部 `C(150,2)=11175` 个无序装备对；
2. 频段不重叠的对直接跳过；
3. 频段重叠的对再逐个检查重复时间区间；
4. 将冲突对去重后写入 `data.json` 和 `result1.xlsx`；
5. 再用独立的离散时频网格方法复核，确保两种方法得到同一批冲突对。

区间法的最坏复杂度约为 `O(N²K²)`，`N` 是装备数，`K` 是单台装备最大重复次数。由于所有数据规模都不大，完整枚举可以直接完成，避免了抽样或只找“看起来严重”的冲突。

## 5. 最终结果

| 冲突类别 | 冲突装备对数 |
|---|---:|
| A–A | 0 |
| A–B | 21 |
| A–C | 66 |
| B–B | 10 |
| B–C | 181 |
| C–C | 19 |
| **合计** | **297** |

| 装备类别 | 装备总数 | 涉及冲突的装备数 | 没有冲突的装备数 |
|---|---:|---:|---:|
| A类 | 20 | 20 | 0 |
| B类 | 40 | 40 | 0 |
| C类 | 90 | 88 | 2 |
| **合计** | **150** | **148** | **2** |

因此：

- 共检查11175个装备对，发现297对冲突；
- 冲突涉及148台装备，占全部装备的98.67%；
- 只有 C007、C060 没有与其他装备冲突；
- B–C 冲突最多，共181对，占全部冲突的60.94%；
- 单台装备最多与8台其他装备冲突，对应 B009、B016、B024、B027、B030、C076。

如果按“时段组合”而不是“装备对”计数，一共会看到431次相交时段。431是冲突发生的次数，297才是题目要求输出的不同装备对数。

## 7. 一句话结论

问题1的核心不是“画一张网络图”，而是先用统一的半开区间规则把冲突定义清楚，再完整检查所有装备对。最终得到297对冲突，后续问题2和问题4就在这批冲突的基础上进行消解。
